# ADR-086 — Bound the AI Execution Layer to Observation Before Routing (link stub)

**Authoritative copy:** [`exeris-docs/adr/ADR-086-bound-the-ai-execution-layer-to-observation-before-routing.md`](https://github.com/exeris-systems/exeris-docs/blob/main/adr/ADR-086-bound-the-ai-execution-layer-to-observation-before-routing.md)

ADR-086 is a **platform-scope** decision owned by `exeris-docs`. It bounds the AI execution layer to observation before routing, and governs the seam between `exeris-agents` and `exeris-ai-execution`.

## Why this stub exists

ADR-086 §A.2 and §H.36 define the relationship between `exeris-agents` and the AI execution layer:
- `exeris-agents` owns event semantics; `exeris-ai-execution` owns their interpretation.
- The telemetry sink contract payload and version are deferred until CI-produced rows demonstrate needs.
- Any change to `exeris-agents` that interprets events, aggregates data, or recommends models is a `[HARD BLOCK]`.

ADR-086's Engineering Protocol item 6 calls for this stub by name.
